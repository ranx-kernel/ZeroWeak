# 🚀 About ZeroWeak

ZeroWeak is a futuristic cybersecurity awareness platform designed to help users identify, prevent, and understand cyber threats in real time.

The platform provides:
- 🔐 AI-powered phishing detection
- 📊 Threat analytics dashboard
- 🧠 Cyber awareness learning modules
- 👨‍👩‍👧 Role-based security modes
- 📈 Real-time risk scoring
- 🛡️ Interactive cyber safety education

ZeroWeak focuses on making cybersecurity simple and accessible for:
- Students
- Families
- Senior Citizens
- Beginners in Cybersecurity
